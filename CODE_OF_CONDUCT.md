# Code of Conduct

We follow the [Contributor Covenant v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short:

- Treat people with respect, in issues, PRs, discussions, and any other public-facing surface of this project.
- Assume good faith. Most disagreements are misunderstandings, not malice.
- Critique ideas, not people. "This API is unsafe because…" is welcome; "you're wrong" is not.
- No harassment, discrimination, or personal attacks. No exceptions.

## Reporting

Violations: email `msquaregiza@gmail.com` with `[flutter-dev-agents COC]` in the subject. Reports are read by the maintainer ([@michal-giza](https://github.com/michal-giza)) only and treated confidentially.

Expect an acknowledgement within 5 business days and an action (warning / temporary block / permanent ban from the project's public spaces) within 14 days.

## Scope

This applies to every public space of the project — GitHub Issues, PRs, Discussions, the project's social-media presence, and any community event where someone is representing this project.
