## ASO discipline

Every text in this folder follows three rules:

1. **First 80 characters carry the value prop.** Some directories truncate after that.
2. **Three keyword clusters appear in every description**: `MCP / Model Context Protocol`, `Flutter / mobile`, `Claude / agent / autonomous testing`. These are the high-volume search terms in this niche.
3. **One concrete number per description** (110 tools, 556 tests, etc.). Numbers convert; adjectives don't.
